Vikey for HarmonyOS NEXT
Modified 2026-11-09

This program is a modified version of Vikey 1.0.32 by Tony Dinh (Đinh Quang Trung),
which is based on OpenKey by Tuyen Mai.

The HarmonyOS NEXT input method, ArkTS interface, and NAPI bridge were added.
The typing engine under Engine/ is the Vikey 1.0.32 engine, built unchanged
except for being compiled for HarmonyOS.
